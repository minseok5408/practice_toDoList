APK를 Android 기기로 전송해 파일을 열고 설치합니다. 별도 개발 앱, Expo Go, PC 연결
또는 서버 없이 APK만으로 실행됩니다. 기기 설정에 따라 파일을 연 앱에 "알 수 없는 앱
설치" 권한을 허용해야 할 수 있습니다.

1.0.0 또는 1.0.1과 동일한 인증서로 서명되어 기존 앱 위에 업데이트할 수 있습니다.
서명 충돌이 표시될 때만 기존 앱을 삭제한 뒤 설치하세요. 앱 삭제 시 기존 로컬 데이터가
함께 지워질 수 있습니다.

이 APK는 직접 전달 및 테스트 설치용 인증서로 서명되었습니다. Google Play에 출시할 때는
별도의 안전한 프로덕션 키와 Google Play App Signing을 사용해야 합니다.

`SHA256SUMS.txt`의 값은 파일이 전달 중 바뀌거나 손상되지 않았는지 확인하는 파일 지문이며,
비밀번호나 설치 코드가 아닙니다.
