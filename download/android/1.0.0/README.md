# MOMENT Android 1.0.0

설치 파일: `moment-1.0.0-android.apk`

- 패키지: `com.minseok5408.practicetodo`
- 버전: `1.0.0` (`versionCode` 1)
- 최소 Android: Android 7.0 (API 24)
- 지원 CPU: `arm64-v8a`, `armeabi-v7a`

APK를 Android 기기로 전송해 연 뒤 설치합니다. 기기 설정에 따라 파일을 연 앱에
대해 "알 수 없는 앱 설치" 권한을 한 번 허용해야 할 수 있습니다.

이 APK는 직접 전달 및 테스트 설치용 키로 서명되어 있습니다. Google Play에
출시할 때는 별도의 안전한 프로덕션 키로 다시 서명해야 합니다.
