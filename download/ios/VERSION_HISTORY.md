- iOS 앱 버전과 빌드 번호 설정: 성공 (`1.0.4`, build 5)
- 앱 내부 알림 권한 사전 안내 코드 반영: 성공
- IPA 빌드: 실패/미완료
- Apple 서명: 미실행
- 실제 iPhone 설치 및 알림 권한 검증: 미실행

### 실패 원인과 개선 방향

- 현재 Windows 환경에는 iOS 네이티브 빌드에 필요한 macOS/Xcode가 없습니다.
- Apple Developer 인증서와 프로비저닝 프로파일이 없어 설치 가능한 서명 IPA를 생성할 수
  없습니다.
- macOS/Xcode 또는 EAS iOS 빌드와 Apple 서명을 준비한 뒤 실제 iPhone에서 사전 안내,
  Apple 시스템 권한 창, 배너 알림과 재실행을 확인해야 합니다.
- 검증되지 않은 IPA를 설치 파일로 제공하지 않습니다.

## 1.0.2

### 성공 여부

- iOS 앱 버전과 빌드 번호 설정: 성공 (`1.0.2`, build 3)
- IPA 빌드: 실패/미완료
- Apple 서명: 미실행
- 실제 iPhone 설치 및 실행: 미실행

### 실패 원인

- 현재 빌드 환경이 Windows라 iOS 네이티브 빌드에 필요한 Xcode를 실행할 수 없습니다.
- Apple Developer 계정, 배포 인증서와 프로비저닝 프로파일이 제공되지 않았습니다.
- 설치 대상 등록 기기 또는 TestFlight 배포 설정도 준비되지 않았습니다.

### 개선 방향

1. Apple Developer Program 계정을 준비합니다.
2. macOS와 Xcode 또는 EAS 원격 iOS 빌드 환경을 사용합니다.
3. 번들 ID `com.minseok5408.practicetodo`의 인증서와 프로비저닝 프로파일을 구성합니다.
4. Ad Hoc 또는 TestFlight로 실제 iPhone에 설치하고 최초 실행과 핵심 기능을 확인합니다.
5. 성공한 IPA를 `ios/1.0.2/moment-1.0.2-ios.ipa`로 보관하고 서명과 SHA-256을 기록합니다.
