- IPA 빌드: 실패/미완료
- Apple 서명: 미실행

현재 Windows 환경에는 iOS 네이티브 빌드에 필요한 Xcode가 없고, Apple Developer 배포
인증서와 프로비저닝 프로파일도 제공되지 않았습니다. 따라서 상대방이 바로 설치할 수 있는
서명된 IPA를 만들었다고 표시하지 않습니다.

완료하려면 macOS와 Xcode 또는 EAS iOS 원격 빌드, Apple Developer Program 계정,
번들 ID `com.minseok5408.practicetodo`용 서명 설정이 필요합니다. 이후 등록 기기 Ad Hoc
설치 또는 TestFlight에서 실제 실행을 확인해야 합니다.
