# 스토어 등록 문안

## 기본 정보

- 앱 이름: Practice Todo
- 부제: 오늘에 집중하는 로컬 투두
- 카테고리: 생산성
- 지원 언어: 한국어, 영어

## 한국어

### 짧은 설명

마감일, 알림, 프로젝트와 안전한 백업을 한곳에서 관리하세요.

### 상세 설명

Practice Todo는 오늘 해야 할 일을 빠르게 정리하고 끝까지 이어가도록 돕는 로컬 우선 투두 앱입니다.

- 빠른 추가와 상세 메모
- 오늘·내일·예정·지연 스마트 화면
- 우선순위, 프로젝트, 태그와 하위 할 일
- 반복 일정과 기기 로컬 알림
- 검색, 정렬, 다중 선택과 드래그 정렬
- 완료 기록, 보관함과 삭제 되돌리기
- JSON 백업·복원과 CSV 내보내기
- 시스템 다크 모드, 한국어·영어와 접근성 지원

할 일 데이터는 기본적으로 사용자의 기기에 저장됩니다. 계정 가입 없이 바로 시작할 수 있습니다.

### 검색 키워드

투두, 할일, 체크리스트, 일정, 알림, 생산성, 메모, 습관

## English

### Short description

Plan tasks, due dates, reminders, projects, and backups in one calm place.

### Full description

Practice Todo is a local-first task manager designed to keep your day focused. Quickly capture a task, add detailed notes, set due dates and reminders, organize projects and tags, break work into subtasks, and review completed work. Search, filters, manual ordering, undo, archive, JSON backup, CSV export, dark mode, Korean and English are included. Your task data stays on your device by default, with no account required.

### Keywords

todo, tasks, checklist, reminder, planner, productivity, notes

## 스토어 개인정보 공개 초안

- 계정: 사용하지 않음
- 광고·추적: 사용하지 않음
- 사용자 콘텐츠: 기기 로컬 저장, 운영자 서버 수집 없음
- 진단 정보: Sentry를 운영 환경에 활성화할 경우 충돌·성능 진단 정보 수집 가능
- 알림: 로컬 알림 권한 사용

실제 Sentry 보관 설정과 배포 구성을 확인한 뒤 App Store 개인정보 항목과 Google Play 데이터 보안 양식에 동일하게 반영합니다.
