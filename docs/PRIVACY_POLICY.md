# Practice Todo 개인정보 처리방침

시행일: 2026년 8월 25일

Practice Todo는 계정 없이 사용하는 로컬 우선 할 일 관리 앱입니다.

## 저장하는 정보

할 일 제목, 메모, 마감일, 알림, 프로젝트, 태그와 앱 설정은 사용자의 기기 내부 저장소에 저장됩니다. 앱 운영자는 이 내용을 별도 서버로 전송하거나 열람하지 않습니다.

사용자가 JSON·CSV 내보내기를 실행한 경우에만 운영체제의 공유 화면을 통해 사용자가 선택한 앱이나 위치로 파일이 전달됩니다. 내보낸 파일의 보관과 공유는 사용자가 관리합니다.

## 알림

알림을 켜면 기기 운영체제의 알림 권한과 로컬 알림 기능을 사용합니다. 알림 일정은 기기에서 처리되며 원격 푸시 서버로 전송하지 않습니다.

## 오류 정보

운영 환경에서 Sentry가 활성화된 경우 앱 버전, 기기·운영체제 정보, 오류 스택과 실패한 작업 종류가 전송될 수 있습니다. 할 일 제목, 메모, 백업 파일 내용과 사용자를 직접 식별하는 정보는 오류 보고서에 포함하지 않도록 구성합니다.

## 권한과 보관 기간

- 알림 권한은 일정 알림 제공에만 사용합니다.
- 앱 데이터는 사용자가 앱 설정에서 초기화하거나 앱을 삭제할 때까지 기기에 남습니다.
- 오류 정보의 보관 기간과 삭제는 실제 출시 전 설정한 Sentry 정책을 따르며, 스토어 개인정보 공개 내용과 일치시킵니다.

## 사용자의 선택

사용자는 알림 권한을 거절하거나 운영체제 설정에서 철회할 수 있습니다. 설정 화면에서 데이터를 내보내거나 초기화할 수 있습니다. 앱 삭제 전 필요한 백업을 직접 내보내야 합니다.
