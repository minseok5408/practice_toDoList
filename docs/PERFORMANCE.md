# 성능 기준

## 현재 적용

- `TodoItem`을 메모해 변경되지 않은 카드의 불필요한 렌더링을 줄였습니다.
- 목록은 초기·배치 렌더 수 12개, 윈도 크기 7로 가상화합니다.
- 프로젝트 조회는 매 카드의 배열 탐색 대신 Map을 사용합니다.
- 1,000개 항목에서 검색과 우선순위 정렬을 30회 반복하는 회귀 테스트를 실행합니다.

## 실기기 측정 절차

1. Development Build에 1,000개 테스트 항목을 준비합니다.
2. React Native DevTools Profiler로 첫 화면, 검색 입력, 완료 토글, 필터 전환을 기록합니다.
3. 느린 Android 기기와 iPhone에서 JS 프레임 드롭, 커밋 시간, 메모리 증가를 기록합니다.
4. 최적화 전후 같은 데이터와 동작으로 비교합니다.

시간 기반 단위 테스트는 심각한 알고리즘 퇴행을 막는 안전망일 뿐 실제 UI 프레임 성능을 보장하지 않습니다. 출시 전 실기기 프로파일링 결과를 이 문서에 추가합니다.
