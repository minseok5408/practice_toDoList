# 실기기 회귀 테스트

앱 버전, OS 버전, 기기명과 결과를 각 실행마다 기록합니다. 알림 검증은 Expo Go가 아닌 Development Build에서 진행합니다.

## 공통 핵심 흐름

- [ ] 추가 → 수정 → 완료 → 삭제 → 되돌리기
- [ ] 앱을 완전히 종료한 뒤 다시 열어 데이터 복원 확인
- [ ] 비행기 모드에서 추가·수정·삭제·복원 및 앱 재실행
- [ ] JSON 백업·복원과 CSV 내보내기
- [ ] 저장 데이터 손상 상태에서 원본 내보내기·재시도·초기화

## 알림

- [ ] iPhone에서 권한 허용·거절 처리, 예약 알림 수신과 수정·삭제 시 취소
- [ ] Android에서 권한 허용·거절 처리, 예약 알림 수신과 수정·삭제 시 취소
- [ ] 반복 할 일 완료 후 다음 알림 재예약
- [ ] 앱이 종료됐거나 오프라인일 때 로컬 알림 수신

## 화면과 키보드

- [ ] 작은 화면에서 버튼·카드·모달 잘림 없음
- [ ] 큰 화면과 태블릿에서 과도한 폭·빈 공간 없음
- [ ] 키보드가 열린 상태에서 추가·편집·저장 버튼 접근 가능
- [ ] 120자 제목과 2,000자 메모의 줄바꿈·스크롤 확인
- [ ] 라이트·다크 모드의 텍스트 대비와 시스템 전환 확인
- [ ] 시스템 글자 크기 최대로 설정해 잘림과 겹침 확인

## 접근성

- [ ] iPhone VoiceOver의 탭 순서·역할·선택/완료 상태 읽기
- [ ] Android TalkBack의 탭 순서·역할·선택/완료 상태 읽기
- [ ] 색상 없이 우선순위와 완료 상태를 구분 가능
- [ ] 모든 주요 동작의 터치 영역이 최소 44×44
